== verdict
  The common AOT block set is identical over all 1610 common rows (f1820-1834), so the common
  code's phase does not move in this window.  In the onset window (f1816-1836) the only block-count
  changes are in the seed's compiled cluster: 2 entries at f1832 and 8 at f1833.  (The f1762/f1763/
  f1766 differences are the boot/transition boundary; f1837 is a 2-entry tail after the state split.)
  f1832 is the frame the park probe already shows a -144 cpu_cycles delta with DP identical; the
  first sampled DP/stack difference is f1834.  So the f1832 cycle delta coincides with a real change
  in the seed's executed cluster, and the f1834 state split follows two frames later: the counter
  is tracking phase at that boundary.
  The -149 delta at f1830 survives with an identical block set in every probed range, so it is a
  sub-block residual (within-block instruction count or per-instruction charge) that AOTBLK cannot
  resolve; an instruction-level AOT charge log would be the next instrument.
