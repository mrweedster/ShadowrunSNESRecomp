== 2. One extra 66-clock poll iteration in the control ==

  The loop repeats while $4212 bit 0 is 1.  Each pass is
  $809D8E -> $809D91 -> $809D94 -> $809D8E.  Master per pass:

  ctrl: 5 reads at [655009096, 655009162, 655009228, 655009294, 655009360]
        pass costs [66, 66, 66, 66]
        loop exit $809D96 at 655009420
  seed: 4 reads at [655009110, 655009176, 655009242, 655009308]
        pass costs [66, 66, 66]
        loop exit $809D96 at 655009368

  d at entry: +14
  d at exit:  -52
  change:     -66
  The -66 is one pass of the loop: the control takes five reads,
  the seed four, and every pass costs 66 master on both tiers.

== 3. The hardware edge is shared; only the sampling straddles it ==

  Every [joy] read of this loop on f1832.  While the timer is
  non-zero, beam + timer is the end of the same busy window.

  leg   beam          timer  beam+timer    val  bit0
  ctrl    655009096    204    655009300   C1   1
  ctrl    655009162    138    655009300   C1   1
  ctrl    655009228     72    655009300   81   1
  ctrl    655009294      6    655009300   81   1
  ctrl    655009360      0            -   80   0

  seed    655009110    190    655009300   C1   1
  seed    655009176    124    655009300   81   1
  seed    655009242     58    655009300   81   1
  seed    655009308      0            -   80   0

  busy-window end, control: [655009300]
  busy-window end, seed:    [655009300]
  Same edge on both legs.  The last busy reads are
    control: beam 655009294 timer 6 (6 clocks before the edge)
    seed:    beam 655009242 timer 58 (58 clocks before the edge)
  control: 4 busy reads then a 5th that sees bit0=0
  seed:    3 busy reads then a 4th that sees bit0=0
  The 14-clock phase is larger than the control's 6-clock margin,
  so its next read lands past the edge and costs a whole pass.

== 4. Only f1832 flips in this window ==

  frame   d_nmi   ctrl reads  seed reads   ctrl first timer   seed first timer   d_c530
   1829    +14            1           1                  0                  0         -
   1830    -20           24          24               1494               1514         -
   1831    +14            1           1                  0                  0         -
   1832    +14            5           4                204                190       -52
   1833     +0            1           1                  0                  0       -40
   1834    -32            1           1                  0                  0       +56
   1835     +0            1           1                  0                  0        +0
   1836     +0            1           1                  0                  0        +0

  Only f1832 reads $4212 a different number of times on the two
  legs (5 vs 4).  On f1830 both read it 24 times; on every other
  frame in the window both read it once.  The flip also needs the
  14-clock phase and a read position near the edge: +14 alone on
  f1829 and f1831 flips nothing, because there the loop arrives
  nowhere near the busy window.

== 5. What this changes ==

  Round 8 left the f1832 opening as a -66 step between $80C11F
  and the first $80C399 entry.  It is not a charge convention and
  not inside $81A99D: from $81A99D to the poll entry the two legs
  are in lockstep apart from the +-40 boundary term, which
  cancels.  The step is one extra iteration of a guest poll loop,
  decided by whether the last read lands before or after a shared
  hardware edge.  The loop itself costs 66 master per pass on both
  tiers, so no amount of re-pricing the compiled path removes it.

  This is why the first meaningful DP cluster is at f1832 and not
  at f1830: the f1830 byte is $7E00126, which round 5 section 8
  showed is written by the same value sequence on both legs and
  sits below S (dead scratch).  The readable onset includes the
  f1832 $7E00000/$01 pair, which $80C530 derives from the H it
  latches; the -66 opening offset moves that latch.

  It also says why a read-time or pricing patch cannot be
  sufficient: the input to the divergence is the frame's own
  +-14..32 phase, sampled against a hard edge.  Removing it means
  removing the frame-edge phase, not the poll or the latch.

== 6. The gate, instrumentation inert ==

  first state byte differing: f1830
  frames differing: 305 of 4575, 895 bytes
  crc32_wram first diff: f1828 0xB615CF19 vs 0xC912779D

  Same binaries as the probe runs, all four env vars unset: it
  reproduces the round-7/round-8 gate exactly (f1830, 305 of 4575,
  895 bytes, crc f1828), so the taps do not perturb the run.
